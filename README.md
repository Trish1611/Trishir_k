## Notes

The hero animation is a cycloidal speed reducer generated from its design equations —
twelve housing rollers, an eleven-lobe disc, one eccentric input — with the
load-carrying rollers highlighted as it turns. Same architecture as the reducer in
my B.E. dissertation, and the reason the page opens on parametric modelling.

Fonts load from Google Fonts; everything else is self-contained.
